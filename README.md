# **Employee Attrition Analysis & Prediction**
A simple practice project to strengthen skills & understanding, we're creating a machine learning model to predict whether or not a employees will part woth the company.
## Dataset
- 8 columns
- 100 observations
- Target variable: Attrition, binary categorical.
## Features
- Data inspection & cleaning
- Label encoding of categorical variables
- Correlation analysis
- Distribution visualisation using matplotlib and seaborn
- Exploratory data analysis
- Hyperparameter tuning
- Decision Tree Classifiers
## Models
We trained, tested and compared three models fit for prediction of categorical data
- Logistic regression
- Naive bayes
- Decision tree classifier
## Libraries Used
- Seaborn
- Matplotlib
- Numpy
- Pandas
- Sklearn.metrics
- Sklearn.preprocessing
- Sklearn.model_selection
- Sklearn.tree
