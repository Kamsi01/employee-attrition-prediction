# **Employee Attrition Analysis & Prediction**
A simple practice project to strengthen skills & understanding, we're creating a machine learning model to predict whether or not a employees will part woth the company.
## Dataset
Dataset from Kaggle, 8 columns, 100 observations, target variable: Attrition, binary categorical.
## Exploratory Data Analysis
EDA was focused on infering relationships between variables by visualisation: testing generic asusmptions as well as finding hidden patterns, and arriving at insightful conslusions.
## Models
We trained and compared three models, a decision tree classifier, a logistic regression model and a naive bayes model.
